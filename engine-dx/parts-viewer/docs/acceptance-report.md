# 부품 구매 뷰어 완료·검증 보고서

작성일: 2026-10-20 (Asia/Seoul). 기준: MAN B&W G95ME-C 계열의 구조 설명용 개념 모델. **실제 제작 치수 아님.** 기존 6G50ME-C9.6 모델은 보존하고 새 G95 부품 모듈을 별도 연결한다.

부품별 JavaScript 원본, 개별 GLB 12개, 전체 6·7·11기통 GLB 3개, SVG 구조 참고도 12개, 객체·연결 JSON, 구매 연결 JSON을 작성했다. 생성 원본은 개념 메시의 반복 수정용이며 정밀 CAD·STEP이 아니다.

화면에는 생산 호기·협력사 선택, 부품 검색·클릭·상세 정보, 자재 상태와 사유, 주변 반투명, 점멸 정지·모션 감소, 단면·연결 분리, JSON 입력·BOM 및 모델 내보내기 인터페이스를 구현했다. 초기 업무 정보는 미등록이며 시연 데이터는 가상임을 표시한다.

## 2. 사용한 근거·확인 치수·가정

R1 공식 11G95ME-C Mark 10.5 포스터의 본문과 전체 페이지 시각 검토를 통해 구조 부품 배치를 확인했다. R2·R3 공식 제품 사진의 큰 외형을 시각 검토했고 R4·R5·R6·R7 공식 본문에서 부품 역할·구매 단위·유압 기능을 확인했다. MBS와 쉘의 관계는 R7 공시 및 MAN 원출원 특허의 설명을 보조 참고했다. 특정 특허 실시예를 G95 확정 설계로 복제하지 않았다.

**모델에 적용한 부품별 확정 제작 치수는 없다.** R1의 원문 숫자 `Bore: 950 mm / 3,460 mm`와 R2의 제품군 범위는 출처 기록에만 남겼다. 메시의 길이·두께·기통 간격·MBS 단면·배관 곡률·끝단·분해 이동량은 단위 없는 시연용 가정이다. 포트 개수·나사산·체결 패턴·냉각유로·밀봉 홈을 임의 정밀 묘사하지 않았다.

후보 A는 실제 브라우저에서 Cummins QSK60 외관 모델임을 확인해 계열 불일치로 제외했다. B는 `Royalty Free License (no AI)`에 따라 입력·다운로드하지 않았다. C의 실제 proprietary LICENSE를 확인하고 코드·GLB·문서를 복사하지 않았다. 추가 베드플레이트 후보는 원본 권리가 확인되지 않아 제외했다. 원문 자료의 파일·그림을 배포물에 포함하지 않았다. 상세 근거는 [출처 기록](./sources-and-accuracy.md)에 있다.

### 한계

- 화면 절단면은 열린 가시성 표현이며 실제 가공 단면·유로·밀봉 구조가 아니다. 분리 보기는 정비·조립 순서 검증이 아니다.
- 2~12기통 생성은 개념 배치 API이며 UI는 6·7·11기통을 제공한다. 각 변형의 실제 제품 유효성을 확정하지 않는다.
- 상태와 수량은 외부에서 제공한 값을 표시한다. 원천 데이터의 정확성·재고 배분·부족 계산·납기 예측을 검증하는 ERP 기능은 포함하지 않는다.
- 실제 협력사 계약·발주·입고·품질 이력과 PDF 분석은 미연결이다. JSON 파일 검증·표시는 연계 인터페이스이며 인증·업무 API·저장소 동기화는 후속 범위다.
- 기존 6G50과 새 G95의 ID·부품·계약을 추정으로 자동 매핑하지 않는다.

## 4. 실제 설계 자료가 추가로 필요한 항목

1. 대상 생산 호기의 승인 엔진 형식·Mark·REV·기통 수와 GA/단면도.
2. 라이너·커버·프레임·베드의 치수·공차·장착부 및 접합 인터페이스 도면.
3. 배기밸브의 승인 BOM, 컴플리트/개별품 구매 범위, 하우징·스핀들·시트·작동부 도면.
4. G95 적용 유압 라우팅·관경·피팅·등급·HPS/HCU 장치와 양 끝 연결 규격.
5. MBS·베드의 통합/주강/용접 상세와 베어링 쉘·캡 분할 도면.
6. 호기별 품목·REV·계약 공급사·재고·배정·발주·필요일·납품일·갱신일 원천.
7. 위 CAD·도면·사진을 웹 표시·수정·배포할 수 있는 권리와 승인된 ID 매핑.

설계 근거가 추가되면 안정적인 `partId`와 호기별 데이터 계약을 유지하면서 개념 형상을 검증된 메시 또는 승인 CAD 변환 모델로 교체할 수 있다.
