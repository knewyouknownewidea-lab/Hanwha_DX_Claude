# 출처·라이선스·모델 정확도 기록

검토일: 2026-10-20 (Asia/Seoul). 기준은 **MAN B&W G95ME-C 계열**이며, 구조 배치는 R1의 **11G95ME-C Mark 10.5**를 참조한다. 기존 플랫폼의 6G50 화면은 보존하고 별도 G95 개념 부품 모듈을 연결한다. 두 엔진을 동일한 실물 모델로 취급하지 않는다. 기통 수 전환은 동일 크기의 모듈을 반복하는 시연 배치이며 해당 기통수의 승인된 실제 엔진 변형을 뜻하지 않는다.

> 구조 설명용 모델 / 실제 제작 치수 아님

## 정확도 수준과 채택 범위

- **확인된 형상·배치**: 공식 포스터의 구조 부품 위치, 공식 제품 사진의 큰 외형을 직접 확인했다. 이는 해당 사진 속 특정 제품을 정밀하게 복제했거나 특정 호기 적용을 확인했다는 의미가 아니다.
- **확인된 치수**: 이번 모델에 채택한 **부품별 확정 제작 치수는 없다**. R1 원문에는 `Bore: 950 mm / 3,460 mm`라는 수치 표기가 있다. 원문을 기록하되 두 수치로 라이너·커버·지지부의 제작 치수를 산출하지 않았다. R2의 범위값도 특정 G95 부품 치수로 사용하지 않았다.
- **개념 형상**: 생성한 모든 메시의 길이·두께·간격·단면·연결 끝단·분해 이동량은 시각화를 위한 가정이다. 사진의 원근으로 실치수를 역산하지 않았다. 좌표의 수치는 실제 미터 또는 밀리미터의 제조 사양이 아니다.

파라메트릭 JavaScript 원본에서 메시를 재생성하며 GLB에 객체명과 `partId`, 출처, `accuracy: concept`, `dimensionsVerified: false`를 유지한다. 제조용 STEP/정밀 CAD 또는 제조도면으로 제출하지 않는다. 좌표계·반복 간격은 `modeling.md`에서 설명한다.

## 실제 업무 적용 전에 필요한 자료

1. 대상 호기의 제조사 승인 GA/단면도, 엔진 형식·Mark·기통수와 REV.
2. 라이너·커버·실린더프레임·프레임박스·베드플레이트의 승인 인터페이스 도면과 실제 치수·단위·공차.
3. TCEV 하우징·스핀들·시트의 승인 BOM, 구매 단위와 상하위 품목 관계.
4. 배관 ISO/라우팅, 실제 HCU/HPS 위치·끝단·직경·압력 등급.
5. MBS의 대상 설계별 주강/용접/통합 구조와 쉘·캡의 분할 도면.
6. 호기별 품목번호·REV·계약 공급업체·배정·재고·발주·일정의 신뢰 가능한 원천.
7. 실제 CAD/사진/도면을 웹 표시하거나 GitHub에 배포할 수 있는 권리.

이 자료를 받기 전에는 실제 재고·납기·협력사 계약을 생성하지 않는다. 초기 회색은 데이터 미확인이며, 시연 호기·시연 협력사·시연 수량은 명시적으로 표시한 가상 데이터다.
