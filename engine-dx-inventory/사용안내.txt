한화엔진 구매 DX · 6G50ME-C9.6 시연 시스템
2026-10-17 / DEMO-CAD-2.0

사용법
1. MAIN 02에서 모델을 드래그하면 회전, 휠로 확대, 우클릭 드래그로 이동합니다.
2. 모델 또는 '부품 선택' 목록에서 부품을 선택합니다. 주황색 강조와 우측 부품 ID를 확인합니다.
3. '내부 단면'은 라이너·재킷·프레임의 +X 절반을 제거한 별도 CAD입니다. 임의 평면 이동식 절단은 아닙니다.
4. 모델 아래 '분리' 슬라이더를 오른쪽으로 이동하면 부품이 벌어집니다. 0%로 되돌리거나 우상단 초기화를 누르면 재조립됩니다. 분리는 관찰용 이동이며 실제 정비 순서를 뜻하지 않습니다.
5. '주변 반투명', '선택 부품만', 부품군 표시 메뉴를 조합하여 내부를 확인합니다.
6. 부품 협의는 선택 부품만, 엔진 전체는 전체 협의를 표시합니다. 검색·상태 필터를 사용할 수 있습니다.
7. 구매팀 계정으로 등록·배정·상태 변경·최종 회신·구매 조치를 수행합니다. 기술부서는 배정된 검토 의견을 기록합니다. 협력사는 자기 회사에 공개된 문의·회신만 봅니다.
8. 각 담당 부서의 검토 완료 이후 전역 '검토 완료'가 허용됩니다. 최종 회신·협력사 확인·5개 구매 후속 조치 판단을 거쳐 '최종 완료'로 진행합니다.
9. 사진·문서 첨부는 5MB 이하 PDF/PNG/JPG/WebP/TXT/CSV입니다. 기본 사내 전용이며 구매팀에서 공개 범위를 지정합니다.

데이터와 인증
- 10개 기본 기술협의 및 모든 계정·업체·발주번호는 가상입니다. 공급관계나 실제 고장·발주를 증명하지 않습니다.
- 로컬 브라우저 검증 중 추가한 1개 가상 협의는 로컬 DB에만 존재합니다. 배포판은 기본 10개로 시작합니다.
- SQL(D1/로컬 SQLite)에 기록, R2(로컬 모의 버킷)에 첨부파일을 저장합니다. 새로고침 후에도 유지됩니다.
- 계정 선택은 시연용입니다. 임의 사용자가 시연 역할을 선택할 수 있으므로 실제 기업 인증·권한 부여가 아닙니다.
- API는 세션으로 역할을 확인하고 업체·부서 범위를 검사합니다. 운영 전 기업 SSO, 실제 사용자/업체 소속 검증, 세션 회수, 보존·백업 정책 등이 필요합니다.
- ERP·MES·PLM에 실제 연결되지 않습니다. 발주·계약을 자동 변경하지 않습니다.
- MAIN 01은 제공된 HTML 원본을 바이트 단위로 보존한 별도 페이지입니다. 그 기존 모의 데이터/기능이 실제 시스템 연동으로 바뀐 것은 아닙니다.

소스 실행 (Node >=22.13, pnpm 11.25)
pnpm install
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_tearful_catseye.sql
pnpm dev --hostname 127.0.0.1 --port 5173
마이그레이션 SQL은 새 DB에 한 번만 적용합니다. 로컬 상태는 .wrangler/state에 저장됩니다.
백엔드 검증: node checks/backend.mjs
타입 검증: node node_modules/typescript/bin/tsc --noEmit
Sites 배포용 설정은 .openai/hosting.json, DB 스키마는 db/schema.ts입니다.

한계
가정 기반 개략 모델입니다. 제작·강도·열·동역학·윤활·정비 검증에 사용할 수 없습니다.
모든 CAD 간섭 검사는 저장된 한 자세의 정적 검사입니다. 크랭크 전 회전의 운동 간섭 검증은 수행하지 않았습니다.
각 부품군은 선택 편의를 위한 개략 솔리드입니다. 실제 체결, 배관 연결, 지지 구조, 밸브 작동, 제어 장치 및 내부 유로는 생략했습니다.
