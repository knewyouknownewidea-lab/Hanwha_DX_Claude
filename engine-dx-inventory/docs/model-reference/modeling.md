# 모델 구조와 편집

이 모델은 선박용 저속엔진의 구매 부품과 연결 위치를 식별하기 위한 **구조 설명용 모델 / 실제 제작 치수 아님**입니다. 기준 계열은 MAN B&W G95ME-C이며 공식 R1 11G95ME-C Mark 10.5 포스터의 전체 구조를 참조합니다. 6·7·11기통 파일은 같은 개념 모듈의 반복 배치이며 각 기통 수의 실제품 설계·납품 가능 구성을 확정하는 자료가 아닙니다.

## 원본과 재생성

- `lib/engine-model/engine-scene.js`: `createEngine(cylinderCount)`가 엔진 객체, ID→객체 Map, metadata, 비선택 보조 객체, 연결 관계를 반환합니다.
- `lib/engine-model/models/*.js`: 부품별 절차적 메시 편집 원본입니다. 정밀 CAD·STEP 원본이 아닙니다.
- `npm run parts:export`: GLB 15개, 부품 구조 참고도 SVG 12개, `public/data/g95-model-manifest.json`을 재생성합니다.
- `public/models/g95-concept/engine-6.glb`, `engine-7.glb`, `engine-11.glb`: 조립 계층을 유지한 전체 웹 모델입니다.
- 독립 부품 파일명: `cylinder-liner`, `cylinder-cover`, `exhaust-valve-assembly`, `exhaust-valve-housing`, `exhaust-valve-spindle`, `exhaust-valve-seat`, `frame-box`, `bedplate`, `hydraulic-pipe`, `main-bearing-support`, `bearing-shell`, `cylinder-frame`의 `.glb`입니다.
- `public/model-reference/index.html`: 각 부품의 정면·측면·개념 절단 참고도로 연결합니다.

출처 원본의 사진·도면·CAD·타사 뷰어 코드를 프로젝트에 포함하지 않습니다. 모델은 독립적으로 작성한 단순화 메시입니다. 근거와 각 자료의 접근 결과는 출처 기록을 함께 확인하십시오.

## 단위·좌표·원점

오른손 좌표계에서 **Y축은 위쪽**, **X축은 크랭크축 방향**, **Z축은 엔진의 가로 방향**입니다. 엔진 X·Z 중심이 원점이며 Y=0은 개념 베드플레이트 기초 바닥입니다. 부품별 원점은 모델 코드의 중심/접합 기준이며 manifest의 `basePosition`으로 조립 위치를 복원합니다.

메시의 모든 숫자는 **단위 없는 시연용 비례**입니다. GLB/glTF가 관례상 1 unit을 nominal metre로 해석하더라도 이 파일의 1 unit은 실제 1 m라는 뜻이 아닙니다. 단위 변환을 적용해 제작에 사용하면 안 됩니다. 엔진 metadata의 `units`, `unitMeaning`, `dimensionsVerified: false`가 이 제한을 기록합니다.

반복 간격 1.70, 라이너 반경·높이, 프레임의 폭·높이, 관의 반경 등 코드의 숫자는 모두 **시연용 가정**입니다. 확인된 부품 제작 치수는 적용하지 않았습니다. R1 등에 명시된 일부 공칭 정보가 있더라도 해당 값으로 이 메시를 정밀 모델로 환산하지 않았습니다. SVG에는 확정 치수선을 넣지 않았습니다.

기통 수를 변경하면 실린더 모듈 개수와 중심 위치만 바뀌며 개별 라이너·커버·밸브를 늘려 변형하지 않습니다. 프레임박스·베드플레이트는 반복 개수에 맞는 개념 구조를 재구성합니다. 생산 호기의 실제 엔진 형식에 따라 공통 구조물 설계 자료와 맞는 검증 모델로 교체해야 합니다.

## 부품과 연결 범위

| 부품 | 표현한 범위 | 확인이 필요한 사항 |
| --- | --- | --- |
| 실린더 라이너 | 중공 본체, 상부 칼라·단차, 프레임 장착 문맥 | 특정 G95 제품의 외경/높이·소기 포트 배열·냉각/밀봉 상세 |
| 실린더 커버 | 커버 본체와 중앙 배기밸브 장착 위치 | 연료기기 장착부·체결 위치/개수·정확 접합면 |
| 프레임박스 | 높은 프레임의 개방형 실루엣, 가이드 주변 | 실제 격벽·보강재·접합 형상 |
| 베드플레이트 | 기초, 양측 종방향 구조, 통합 축 지지 영역 | 정확한 횡거더·용접/주조·장착 상세 |
| 배기밸브 | 조립체 상위 노드 및 하우징·스핀들·시트 하위품 | 특정 TCEV95 제품 단면·스트로크·유압 작동부 상세 |
| 유압 배관 | 밸브측/공급측 끝단, 개념 곡선 경로 | 실제 G95 적용 배관 경로·관경·피팅·연결 규격 |
| MBS / 쉘 | 서로 다른 객체와 ID, 축 지지 관계 | 해당 엔진의 통합 설계·실제 별도 구매 범위 |
| 실린더 프레임 | 라이너 장착 슬리브와 프레임박스 연결 문맥 | 실제품 재킷/냉각부·접합 상세 |

베드플레이트 내 MBS는 **통합 지지 영역**으로 취급합니다. 독립 ID와 독립 GLB는 식별·데이터 연결을 위한 것이며 탈착 가능한 부품이라고 주장하지 않습니다. `integrated: true`이며 분해 보기의 이동 벡터는 `[0,0,0]`입니다. 쉘은 별도 객체·ID이며 현재는 위치 확인용 보조 품목입니다. 특허 R7의 특정 실시예를 G95의 확정 형상으로 복제하지 않았습니다.

피스톤·로드·크로스헤드·크랭크축·공급측 축선은 연결 위치를 설명하는 비선택 보조 형상입니다. 실제 운동학·크랭크 위상·공급장치 위치의 근거가 아닙니다. 확인되지 않은 나사산·볼트 개수·냉각유로·밀봉홈·관 규격을 만들지 않았습니다.

## ID·품목·조립체

`partId`는 3D 위치/분류 ID입니다. 실제 품목번호·REV·협력사·발주 정보는 생산 호기를 키로 별도 연결합니다. 예를 들어 `CYL01_LINER`라는 위치에 호기마다 서로 다른 실제 품목을 연결할 수 있습니다. 기통은 `CYLINDER_01` 아래에 반복되며 공유 구조는 `shared_structure` 아래에 있습니다.

`CYL01_EXHVALVE`는 상위 조립체이고 `_HOUSING`, `_SPINDLE`, `_SEAT`는 하위품입니다. `bomRole`과 `parentPartId`를 유지합니다. 조립체 구매 시 하위품의 필요량을 다시 더하지 않으며 실제 구매 정책에 따라 조립체/하위품 중 집계 단위를 선택해야 합니다. 모델의 객체 수가 구매 필요량을 뜻하지 않습니다.

내보내기 시 Group 이름과 `extras.partId`에 ID를 보존합니다. manifest에는 부품 metadata·계층·연결 관계·파일 매핑을 기록합니다. `basePosition`과 `explodeVector`는 설명용 보기 배치이며 실제 탈착 절차·정비 여유 공간이 아닙니다.

## 단면·분해 보기의 한계

단면은 렌더러 또는 참고도 생성기의 평면 클리핑입니다. 절단된 표면은 닫거나 제조도면처럼 해칭하지 않으며, 열린 메시가 실제 가공면·벽 두께·숨겨진 냉각구조를 증명하지 않습니다. 분해 보기는 식별을 위해 부품을 떨어뜨려 보여 주는 개념 배치입니다. 배관의 늘어난 거리나 접합부 틈이 실제 작업 절차를 뜻하지 않습니다. MBS 통합 영역과 쉘은 분해 이동시키지 않습니다.

실제 제작/장착 모델로 바꾸려면 해당 호기의 승인 조립도, 부품 제작도와 REV, 라이너 장착/냉각/소기 포트 상세, TCEV 도면, 유압 배관도·피팅 목록, 프레임/베드/MBS 통합 구조 자료, 원본 CAD의 웹 표시·수정·재배포 권한이 필요합니다.
